# RFID-ATTADANCE-SYSTEM
IoT-based smart attendance system using ESP32, RC522 RFID, Google Sheets, and Google Apps Script, with LED and buzzer feedback and live attendance dashboard integration.

## Run and deploy

This repository includes the attendance dashboard application.

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Configure `GEMINI_API_KEY` in `.env.local` (or through your deployment environment).
3. Run the app:
   `npm run dev`
